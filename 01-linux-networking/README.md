# Linux and Networking Fundamentals

Status: Planned — implementation has not started.

## Project objective

Build confidence administering a Linux host and diagnosing how traffic moves between systems.

## Technologies

Linux, Bash, SSH, iproute2, curl, dig, ss, systemd

## Learning goals

- Navigate the filesystem and manage users, groups, permissions, and processes.
- Explain IP addressing, subnets, DNS, ports, routing, and TCP versus UDP.
- Use logs and network tools to isolate connectivity problems.

## Prerequisites

- A Linux VM, Linux workstation, or WSL environment with administrative access.
- Basic familiarity with a terminal and a text editor.

## Implementation checklist

- [ ] Record the lab environment and draw a simple network diagram.
- [ ] Practice file operations, users, groups, permissions, and process management.
- [ ] Inspect network interfaces, IP addresses, routes, DNS resolution, and listening ports.
- [ ] Configure SSH access in the lab and explain key-based authentication.
- [ ] Inspect a service with systemd and locate its logs where supported.
- [ ] Diagnose a deliberate DNS, port, or permission failure and record the fix.
- [ ] Document commands, sanitized output, and lessons learned; remove temporary lab resources.
